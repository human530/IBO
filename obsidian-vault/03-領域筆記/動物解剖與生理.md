# 🐾 動物解剖與生理

> **一句話**：所有系統都在做同一件事 —— **恆定（homeostasis）＋負回饋**。
> 國際 IBO **最大塊（25%）**；台灣初賽歸**動物學 24 分**。主讀 [[Vander-人體生理學]]，免疫搭 [[Janeway-免疫學]]。

## 🧱 核心架構：每個系統都是控制迴路

> **刺激 → 受器 → 中樞（整合）→ 動器 → 反應 → 回饋**

## 🧪 必背機制（依系統）

- **神經**：靜止膜電位（鈉鉀幫浦 + K⁺ 外漏）→ 去極化達閾值 → **動作電位（全有全無）** → 跳躍式傳導 → 突觸（神經傳遞物）。
- **循環**：心動週期（收縮/舒張）；左心室壓最高；血壓 = 心輸出量 × 周邊阻力。
- **呼吸與酸鹼**：O₂ 由血紅素運送（**S 形解離曲線**，波耳效應：CO₂/H⁺↑ 右移放氧）；CO₂ 多以 HCO₃⁻ 運送，調節血液 pH。
- **腎（排泄/滲透調節）**：腎絲球過濾 → 再吸收 → 分泌 → 排泄；**ADH** 調水分、**醛固酮**調 Na⁺/K⁺。
- **內分泌**：負回饋軸（下視丘–腦垂腺–標的腺）；血糖：胰島素↓糖、升糖素↑糖。
- **免疫**（台灣歸細胞學）：先天（屏障、發炎、補體、吞噬）→ 適應（T 細胞胞媒、B 細胞抗體；**V(D)J 重組**造多樣性；記憶細胞）。

## 🧮 必背數量關係

| 名稱 | 式子 |
| --- | --- |
| 血壓 | BP = 心輸出量(CO) × 周邊阻力(TPR) |
| 心輸出量 | CO = 心搏量(SV) × 心跳(HR) |
| 腎清除率 | C = (U×V)/P |

## ⚠️ 高頻陷阱

- 動作電位是**全有全無**；刺激強度由**頻率**而非振幅編碼。
- 氧解離曲線右移 = **放氧增加**（組織需氧時）。
- ADH 作用在**集尿管**增加水回收（缺水時分泌↑、尿濃）。
- 負回饋是**抑制**偏離；正回饋（分娩、排卵 LH 峰）是**放大**，較少見。
