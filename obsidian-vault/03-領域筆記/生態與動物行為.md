# 🌍 生態與動物行為

> **一句話**：生態是「生物與環境＋彼此」的數量關係；行為是「為什麼這樣做」的演化解釋。
> 台灣初賽把**行為學併入生態學 24 分**。主讀 [[Campbell-Biology]] 生態與行為單元。

## 🧱 核心架構

1. **族群** → 成長模型、調節因子。
2. **群落** → 種間關係、消長。
3. **生態系** → 能量流、物質循環。
4. **行為** → 本能/學習、溝通、社會與利他。

## 🧪 必背機制

- **族群成長**：指數成長（資源無限，J 形）vs **邏輯成長（S 形，受 K 環境承載量限制）**。
- **種間關係**：競爭（−/−）、掠食/寄生（+/−）、互利（+/+）、片利（+/0）。**競爭排除原則**：完全競爭者不能共存。
- **能量流**：單向遞減，**每營養階約 10% 傳遞效率**（十分之一律）→ 食物鏈短。
- **物質循環**：碳、氮（固氮→硝化→脫硝）、磷（無氣體相）。
- **行為**：
  - 本能（固定動作型）vs 學習（習慣化、印痕、聯想學習、頓悟）。
  - **利他與親緣選擇**：**Hamilton 法則 rB > C**（r=親緣度）。
  - 性擇：誇張性狀因配偶選擇而演化。

## 🧮 必背公式

| 名稱 | 式子 |
| --- | --- |
| 指數成長 | dN/dt = rN |
| 邏輯成長 | dN/dt = rN·(K−N)/K |
| 能量傳遞 | 約 10% / 營養階 |
| Hamilton 法則 | rB > C（利他演化） |

## ⚠️ 高頻陷阱

- 邏輯成長在 **N = K/2** 時成長速率最大（不是 N 最大時）。
- 能量「**流動**」單向遞減；物質「**循環**」可再利用 — 兩者別混。
- 親緣選擇用 **rB > C** 判斷利他是否被天擇青睞。
