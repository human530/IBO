# 🔬 細胞與分子生物學

> **一句話**：細胞是會自我維持的化學工廠；分子生物是讀懂它的「程式碼與開關」。
> 台灣初賽歸**細胞學（含微生物、免疫）24 分**；分子/生化部分歸**遺傳學 24 分**。主讀 [[Campbell-Biology]] → 深化 [[Molecular-Biology-of-the-Cell]]、[[Lehninger-生物化學]]。

## 🧱 核心架構（先建這張地圖）

1. **化學基礎** → 水、四大生物分子（醣脂蛋白核酸）、鍵結。
2. **能量** → ΔG、ATP 耦合、酶催化。
3. **代謝** → 呼吸（糖解→丙酮酸氧化→檸檬酸→氧化磷酸化）／光合。
4. **資訊** → 中心法則（DNA→RNA→蛋白）、基因調控。
5. **控制** → 訊息傳遞、細胞週期、凋亡。

## 🧪 必背機制

- **膜運輸**：被動（簡單/促進擴散、滲透，順梯度不耗能）vs 主動（逆梯度耗 ATP，如鈉鉀幫浦）。胞吞/胞吐搬大分子。
- **酶動力學**：
  - 競爭性抑制 → **Vmax 不變、Km↑**（可被高受質克服）。
  - 非競爭性抑制 → **Vmax↓、Km 不變**。
  - 別構/回饋調控 → 開關代謝路徑。
- **細胞呼吸**：最多 ATP 來自**氧化磷酸化（化學滲透）**，O₂ 是最終電子受體；糖解與檸檬酸僅受質層次磷酸化。
- **訊息傳遞**：GPCR → G 蛋白 → 腺苷酸環化酶 → cAMP（第二傳訊者）→ PKA。受體酪胺酸激酶走另一路。
- **細胞週期**：cyclin–CDK 驅動；**檢查點（G1/S、G2/M、紡錘體）**把關；**p53** 偵測 DNA 損傷 → 修復或凋亡。

## 🧮 必背公式

| 名稱 | 式子 |
| --- | --- |
| 自由能 | ΔG = ΔH − TΔS（ΔG<0 自發） |
| Michaelis–Menten | V = Vmax·[S] / (Km + [S]) |
| pH | pH = −log₁₀[H⁺] |
| 有氧呼吸 | C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O（約 30–32 ATP） |

## ⚠️ 高頻陷阱

- 競爭 vs 非競爭抑制的 Km/Vmax 變化**最常被考反**。
- 「最多 ATP 的階段」答**氧化磷酸化**，不是檸檬酸循環。
- 化學滲透是「**質子梯度推動 ATP 合成酶**」，不是電子直接做功。
