# 🧬 遺傳與演化

> **一句話**：遺傳講「資訊怎麼傳給下一代」，演化講「族群層級的資訊怎麼隨時間改變」。
> 台灣初賽歸**遺傳學 24 分（含生技、分子、生化）**。主讀 [[Genetics-Brooker]] + [[Campbell-Biology]] 演化單元。
> 📌 本庫題庫中 **`基因頻率` 是唯一重複出現的高頻考點** → 哈溫定律必拿。

## 🧱 核心架構

1. **傳遞遺傳** → 孟德爾（分離、自由組合）→ 延伸（不完全顯性、共顯、複對偶、上位、性聯、連鎖）。
2. **分子遺傳** → DNA 複製、轉錄、轉譯、突變、調控。
3. **族群遺傳** → 哈溫平衡、演化五力。
4. **演化** → 天擇、遺傳漂變、基因流、物種形成。

## 🧪 必背機制

- **連鎖與重組**：同條染色體基因一起遺傳；交叉互換產生重組型，**重組率 = 重組型/總數 × 100%**，可作圖（1% ≈ 1 cM）。
- **哈溫平衡（HWE）**：在「**無突變、無遷移、無天擇、隨機交配、族群夠大**」下，基因頻率世代不變。
- **演化五力**：突變、基因流、遺傳漂變（小族群明顯）、非隨機交配、天擇。
- **物種形成**：異域（地理隔離）vs 同域（生殖隔離先發生，如多倍體）。
- **天擇型式**：方向性、安定性、分裂性。

## 🧮 必背公式（哈溫）

| 名稱 | 式子 |
| --- | --- |
| 對偶基因頻率 | p + q = 1 |
| 基因型頻率 | p² + 2pq + q² = 1 |
| 隱性帶因者 | 帶因者(Aa) = 2pq |
| 卡方檢定 | χ² = Σ (O−E)² / E |

> 解題訣竅：題目給隱性表現型比例 = q² → 開根號得 q → p=1−q → 帶因者 2pq。

## ⚠️ 高頻陷阱

- 求帶因者要用 **2pq**，不是 q。
- HWE 五條件**任一被破壞**就不平衡（題目常用「天擇/小族群/非隨機交配」破壞）。
- 遺傳漂變在**小族群**才顯著；天擇有方向、漂變無方向（隨機）。
- 連鎖題：重組率最大 50%（等於獨立分配），不會超過。
