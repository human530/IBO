# ⚖️ 五域 vs 七域：台灣初複賽 與 國際 IBO 的權重差異

> **核心發現**：台灣**初賽／複賽**用**5 大領域、各 20%（均等）**；國際 **IBO 理論**用 **7 領域、權重不均**。
> 兩者切法不同，**讀書配比也該不同**。本專案 App（`src/data/domains.ts`）用的是**國際 7 域權重**，
> 報名初賽時要自行換算回**台灣 5 域均等**。

## 一、兩套分類並排

### 台灣初賽 5 大領域（各 24 分 / 20%）

| 台灣領域 | 內含子題 |
| --- | --- |
| 細胞學 | 細胞、**微生物**、**免疫** |
| 植物學 | 植物形態生理、系統分類及演化 |
| 動物學 | 動物形態生理、系統分類及演化 |
| 遺傳學 | 生技、分子生物、遺傳、**生化** |
| 生態學 | 生態、**行為**、系統分類及演化 |

### 國際 IBO 7 領域（權重不均，見 `src/data/domains.ts`）

| IBO 領域 | 權重 |
| --- | --- |
| 動物解剖與生理 | **25%** |
| 細胞生物學 | 20% |
| 遺傳與演化 | 20% |
| 植物解剖與生理 | 15% |
| 生態學 | 10% |
| 動物行為 | 5% |
| 生物系統分類 | 5% |

## 二、對照與「被藏起來」的考點

| 子題 | 國際 7 域歸屬（權重） | 台灣 5 域歸屬 |
| --- | --- | --- |
| 免疫學 | 動物/細胞 | **細胞學** ⬆️ 提權 |
| 微生物學 | （細胞/分類） | **細胞學** ⬆️ 提權 |
| 生物化學 | 細胞（20%） | **遺傳學** ⬆️ 提權 |
| 動物行為 | 動物行為（5%） | **生態學** ⬆️ 提權 |
| 系統分類與演化 | 系統分類（5%） | **拆到** 植物／動物／生態三領域 |

## 三、策略結論（重要）

1. **初賽要「均等」配置時間**：5 域各 20%，不像國際那樣動物獨大。
   ⇒ 別把時間全壓在動物生理，**植物學、生態學各 24 分絕不能放掉**。
2. **高 CP 值的「隱藏加權」**：在台灣切法下，**免疫、微生物（→細胞學）**與**生化（→遺傳學）**
   的邊際價值比國際權重看起來更高。很多人忽略它們，正是拉開差距的地方。
   ⇒ 對應 [[Janeway-免疫學]]、[[Lehninger-生物化學]]、[[延伸與題本書單]]（Brock 微生物）。
3. **系統分類別當獨立大科**：它被打散在植/動/生態裡，用**親緣樹思維**融入各科即可（見 [[生物系統分類]]）。
4. **複賽再向國際靠攏**：複賽 B 卷與選拔營題目更整合、更像國際 IBO，動物生理深題比重上升
   ⇒ 此時加重 [[Vander-人體生理學]]、[[Molecular-Biology-of-the-Cell]]。

## 四、一句話記法

> **初賽＝五等分（雨露均霑，補免疫/微生物/生化）；國際＝動物最大（25%），分類/行為最小（各 5%）。**
